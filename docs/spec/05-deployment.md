# Развёртывание

## Разработка
`make up` — сборка образа и запуск PostgreSQL + приложения (порт 8080).
`make demo` — запуск из готового образа без интернета. `make seed` — справочники из
`data/snapshots` (очищает справочники). `make test` — build + vet + test.
Обновление существующей базы без потери расписаний — `make db-migrate`: миграции 0003–0008
идемпотентны (`IF NOT EXISTS`).

## Сервер кафедры
`make package` собирает `dist/uni-scheduler.tar.gz`:

| В архиве | Зачем |
|---|---|
| `images.tar` | образы приложения и PostgreSQL — сервер без интернета |
| `docker-compose.yml` | запуск из образов, без сборки |
| `.env.example` | порт (по умолчанию 18080), пароль БД |
| `migrations/` | схема БД |
| `seed.sql` | справочники без расписаний; начинается с очистки демо-данных миграции 0001 |
| бинарники Linux и Windows | запуск без Docker |

PostgreSQL наружу не публикуется: нет конфликта с занятым 5432, база не видна из сети.
Образы собраны под x86-64.

Проверка пакета: распаковка и запуск «как на сервере» на отдельном порту, сверка справочников
с рабочей базой, генерация, просмотр, Excel.
