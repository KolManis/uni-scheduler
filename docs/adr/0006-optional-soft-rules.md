# ADR-0006: Дополнительные правила — выключаемые мягкие штрафы

Принято · 2026-09-23 · `2d308af`, `db5bfe9`

## Контекст
Пожелания к расписанию: лекция по предмету раньше практики в неделе; лекция и практика в один
день, сначала лекция; несколько лабораторных одного предмета — в один день. Сделать их жёсткими
нельзя: потоковую лекцию слушают до 10 групп, а практики у каждой свои, часто у разных
преподавателей.

## Решение
Три независимых правила, по умолчанию выключены — основной алгоритм без них не меняется.
Мягкие штрафы при построении и в оценке: 2000, 2000 и 3000 — меньше штрафа за одиночный день,
чтобы правило не создавало форточек. Какие правила включены, хранится с расписанием
(`schedules.options`, миграция 0005): иначе разбивка разошлась бы со score.

Лекция и практика — разные учебные планы; связь по названию без пометки вида в скобках
(`subjectKey`). Это эвристика: «Programming (Python)» и «Программирование (Python)» не связываются.

## Подтверждение (по одному прогону на вариант, 120 с)
| Правило | Без правила | С правилом |
|---|---|---|
| Практика раньше лекции в неделе | 44 случая | 13 |
| Практики одного предмета в разные дни | 23 | 7 |
| Практика в день лекции после неё | 21 из 125 (17%) | 44 из 126 (35%) |

Окна 0, дней с одной парой 1–3 — основные показатели не просели.

## Последствия
Score с правилами и без напрямую не сравнивается: правила добавляют свои статьи штрафа.
Сравнивать по счётчикам качества (ADR-0011).
