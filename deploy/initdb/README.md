Файлы *.sql из этой папки Postgres выполняет один раз — при создании базы на пустом томе.

- Пакет для сервера (make package) кладёт сюда seed.sql: схема и справочники кафедры.
- При установке из git папка остаётся пустой: схему создаёт приложение при старте,
  справочники загружает команда `docker compose exec app /scheduler seed`.
