# Назначение и требования

## Назначение
Автоматическое составление недельного расписания занятий кафедры по учебной нагрузке
с учётом аудиторного фонда, групп и ограничений преподавателей. Первый пользователь —
кафедра ИТАС; архитектура рассчитана на расширение до факультета и университета.

## Пользователи
| Роль | Что делает |
|---|---|
| Составитель расписания (диспетчер кафедры) | ведёт справочники и планы, запускает генерацию, правит пары вручную, выгружает Excel |
| Внешняя система | работает через REST API |

## Функциональные требования
| № | Требование | Где реализовано |
|---|---|---|
| ФТ-1 | Ведение справочников: корпуса, кафедры, аудитории, группы, преподаватели, учебные планы | веб `/ui/*`, REST `/api/v1/*` |
| ФТ-2 | Импорт справочников из Excel | `POST /api/v1/import/excel` |
| ФТ-3 | Генерация расписания с выбором метода улучшения и таймаута | форма «Расписания», `POST /schedules/generate` |
| ФТ-4 | Генерация всеми методами сразу для сравнения | «Все методы — сравнить» |
| ФТ-5 | Необязательные мягкие правила (лекция и практика) | галочки формы, ADR-0006 |
| ФТ-6 | Просмотр по дням и по группам, с подсветкой окон | `/ui/schedules/{id}`, `/groups` |
| ФТ-7 | Показатели качества по чётной и нечётной неделе, разбивка score | блоки на странице расписания |
| ФТ-8 | Отчёт о неразмещённых парах с возможными причинами | таблица «Не удалось разместить» |
| ФТ-9 | Ручной перенос пары с проверкой конфликтов | «Изменить», `PATCH …/assignments/{idx}` |
| ФТ-10 | Выгрузка в Excel по преподавателям и группам | `GET /schedules/{id}/excel` |
| ФТ-11 | Справка для пользователя | `/ui/help` |

## Нефункциональные требования
| № | Требование | Как обеспечено |
|---|---|---|
| НТ-1 | Жёсткие ограничения не нарушаются никогда | проверка при построении, каждом ходе поиска, ручном переносе |
| НТ-2 | Время генерации задаёт пользователь, по умолчанию 2 минуты | таймаут формы, бюджет солвера |
| НТ-3 | Воспроизводимость построения | сортировка входа, ADR-0008 |
| НТ-4 | Генерация не теряется при закрытии вкладки | генерация и сохранение не зависят от запроса |
| НТ-5 | Работа без интернета на сервере | пакет с образами, `deploy/` |
| НТ-6 | Расширяемость: новый транспорт или хранилище без правки алгоритма | гексагональная архитектура, ADR-0001 |

## Границы (что не делается)
- Экзамены и сессия.
- Привязка к календарным датам семестра.
- Выбор чётности и частоты пар по часам за семестр — предложено, ADR-0013.
- Иерархия факультетов.
