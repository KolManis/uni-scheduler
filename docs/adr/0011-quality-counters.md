# ADR-0011: Качество показывается счётчиками, а не только score

Принято · 2026-09-23 · `4ee0ff5`

## Контекст
Score — сумма штрафов с подобранными весами. По нему не видно, что именно плохо; при включённых
дополнительных правилах score с правилами и без несравним. Счётчики дважды показали проблемы,
которых score не показывал: форточки как главную слабость (ADR-0003) и скрытые окна чётной
недели (ADR-0009).

## Решение
- `CalculateQuality`: окна у групп, дни с одной парой, пары в субботу, максимум пар в день у
  группы и у преподавателя — отдельно для чётной и нечётной недели.
- Блок «Качество расписания» на странице расписания.
- `cmd/bench`: несколько прогонов каждого метода, CSV со score и счётчиками.

## Последствия
Любое изменение солвера проверяется серией прогонов по счётчикам, а не одним числом score.
