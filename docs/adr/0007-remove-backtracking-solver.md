# ADR-0007: Удалён поиск с возвратом, солвер один

Принято · 2026-09-23 · `5ad426b`

## Контекст
В проекте было два солвера: основной teacher-driven и старый поиск с возвратом
(`solver_type = "subject"`). На реальных данных старый давал score 918 020 против ~13 000 и не
размещал 3 пары. Кроме того, основной солвер вызывал старый как запасной путь: если хотя бы одна
пара не помещалась, весь результат выбрасывался и заменялся результатом старого солвера —
незаметно для пользователя.

## Решение
Старый солвер и запасной путь удалены. Не поместившиеся пары попадают в отчёт «Не размещено»,
остальное расписание доводится до конца. API на `solver_type`, отличный от `teacher`, отвечает
400 с объяснением.

## Альтернативы
Оставить как базовую линию для сравнения. Отклонено по решению автора; для сравнения методов
остаются пять метаэвристик (ADR-0012).

## Последствия
На текущих данных запасной путь не срабатывал, но на других данных пользователь получил бы
расписание в десятки раз хуже без объяснения.
