# Архитектурные решения (ADR)

Каждый файл — одно решение: почему оно понадобилось, что выбрано, от чего отказались,
чем подтверждено. Решения не переписываются задним числом: если решение пересмотрено,
заводится новое ADR, а старое получает статус «Заменено ADR-NNNN».

| № | Решение | Статус |
|---|---|---|
| [0001](0001-hexagonal-architecture.md) | Гексагональная архитектура: ядро не зависит от адаптеров | Принято |
| [0002](0002-no-group-splitting.md) | Занятие ставится всем группам плана одновременно, без деления | Принято |
| [0003](0003-single-class-day-in-construction.md) | Дни с одной парой устраняются при построении, а не штрафом | Принято |
| [0004](0004-teacher-day-norm.md) | Норма преподавателя — 3–4 пары в день | Принято |
| [0005](0005-sport-rooms-no-transitions.md) | Спортзал и стадион не штрафуются за переходы между корпусами | Принято |
| [0006](0006-optional-soft-rules.md) | Дополнительные правила — выключаемые мягкие штрафы | Принято |
