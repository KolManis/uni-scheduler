# ADR-0015: Второе построение — DSatur, и вставка непоставленных пар

Принято · 2026-09-24

## Контекст
Построение по преподавателям (ADR-0007) ставит пары блоками: преподаватели от самых
ограниченных к самым гибким, все пары преподавателя подряд. Пары последних преподавателей
получают остатки сетки, даже если они труднее пар тех, кто шёл раньше: трудность пары зависит
от её групп, потока и аудиторий, а не только от преподавателя.

Отдельно: пара, не поместившаяся при построении, уходила в «Не размещено» навсегда. Улучшение
двигает только поставленные пары, а score за непоставленные не штрафует.

## Решение
- **DSatur** (`dsatur.go`, `solver_type = "dsatur"`) — построение из раскраски графов: на каждом
  шаге ставится пара с наименьшим числом оставшихся допустимых слотов. Слот выбирается той же
  функцией штрафа, что и в построении по преподавателям; различается только порядок.
  Построение по преподавателям остаётся по умолчанию.
- **Вставка непоставленных** (`unplaced_insert.go`) — после построения и в конце улучшения:
  свободный слот, а если его нет — вытеснение до трёх мешающих пар с их перестановкой.
- Алгоритм построения сохраняется в `options.construction` и показывается на странице
  расписания; при «Все методы» с DSatur в названии стоит «DSatur, <метод>».

## Подтверждение
`go run ./cmd/bench -snapshots data/snapshots -construct teacher,dsatur -runs 2 -budget 45s`,
362 пары, все поставлены в обоих вариантах.

Сразу после построения (без улучшения):

| | Score | Окна (чёт/нечёт) | Дни с одной парой (чёт/нечёт) |
|---|---|---|---|
| По преподавателям | 295 600 | 14 / 13 | 40 / 33 |
| DSatur | 80 960 | 0 / 1 | 27 / 10 |

После улучшения, score (два прогона):

| Метод | По преподавателям | DSatur |
|---|---|---|
| Iterated local search | 4720–5190 | 5130 (заканчивает за 27–29 с из 45) |
| Отжиг | 5230–6600 | 5760–7030 |
| Табу | 8160–8230 | 6400–7100 |
| Генетический | 5190–6820 | 5130–5660 |
| LNS | 5320–5680 | 5220–5690 |

Проверка на уплотнённых данных (у преподавателей случайно закрыто 40–75% будних слотов, по пять
наборов) — без выигрыша: оба построения оставили одинаковое число непоставленных пар
(0 / 7 / 19 / ~67), вставка поставила 0–2 пары из них. Оставшиеся упираются в пересечение
занятости преподавателя и групп, которое вытеснение трёх пар не разрешает.

## Последствия
- После улучшения построения дают близкий score: разница меньше разброса между прогонами.
  Раньше улучшение не успевало сойтись (ADR-0014), и стартовая точка решала больше.
- DSatur заметно помогает табу-поиску и ускоряет сходимость ILS; при коротком таймауте
  стартовое качество важнее.
- Вставка на текущих данных почти не срабатывает; нужна там, где построение оставляет пары,
  которые можно поставить перестановкой соседей.
