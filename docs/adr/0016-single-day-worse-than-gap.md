# ADR-0016: День с одной парой дороже окна; окно в 2+ пары — жёсткое ограничение

Принято · 2026-09-24 · частично заменяет ADR-0003

## Контекст
В ADR-0003 штраф за день с одной парой (4000) сделан меньше половины штрафа за окно (10 000),
чтобы поиск не склеивал два одиночных дня в один день с окном. Решение заказчика обратное:
подождать пару между занятиями лучше, чем ехать в университет ради одной. Окно в две пары и
больше подряд недопустимо вовсе.

К этому моменту улучшение сходится полностью (ADR-0014): на `data/snapshots` окон 0, дней с
одной парой 1 на две недели, так что смена весов почти не меняет результат, а меняет правило.

## Решение
- День с одной парой — 12 000, окно в одну пару — по-прежнему 10 000.
- **HC8**: у группы нет окна в 2+ пары подряд в каждой учебной неделе.
  - Улучшение: перенос, после которого длинных окон у затронутых групп стало больше, отвергается
    (`evaluator.apply`). Снятие и постановка снятых пар (LNS, вставка) проверяются только
    итоговым score.
  - Построение: слот с длинным окном получает штраф 1 000 000, то есть выбирается, только если
    других нет. Делать ограничение абсолютным при построении не стали: пара ушла бы в
    «Не размещено», а поставленную поиск ещё может переставить.
  - Оценка: 1 000 000 за длинное окно; в блоке качества — счётчик «Окна в 2+ пары подряд».
  - Ручной перенос HC8 не проверяет: это решение человека, результат виден в блоке качества.

## Подтверждение
`go run ./cmd/bench -snapshots data/snapshots -construct teacher,dsatur -runs 2 -budget 45s`.
Во всех 20 прогонах: длинных окон 0, окон у групп 0–1, дней с одной парой 1–2 на две недели,
все пары поставлены — как и до изменения. Score вырос за счёт веса одиночного дня и напрямую
с прежним не сравним.

| Метод | По преподавателям | DSatur |
|---|---|---|
| Iterated local search | 15 600–15 620 | 8790–9160 |
| Отжиг | 11 500–11 860 | 9630–11 830 |
| Табу | 16 420–22 200 | 10 530–10 560 |
| Генетический | 15 280–20 510 | 10 120–15 330 |
| LNS | 13 520–17 440 | 16 900–19 700 |

С новыми весами DSatur + ILS даёт лучший и самый стабильный результат.

## Последствия
- Эталон сходимости (`TestGolden_Converge`) изменился: на маленьком примере поиск собирает
  четыре пары группы в один день (score 3600 вместо 2400) — с дорогим одиночным днём до двух дней
  по две пары одиночными ходами не дойти.
- Если построению некуда поставить пару без длинного окна, такое окно остаётся и видно в отчёте.
